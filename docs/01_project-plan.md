# 01. 企画方針

> このファイルは公開リポジトリに置くため、特定の学校名・過去問の年度・出題実績は記載しません。
> 内部調査の内容は非公開の内部資料で管理します（`internal/`、git管理外）。

## 1. サイトの目的

単なる文学史の暗記サイトではなく、**作家・作品・時代・文学的なつながりを体系的に学べる**サイトを作る。

提供する学習：

- 作家と代表作品を覚える
- 作家の活動時代や文学史上の位置付けを理解する
- 作家同士の関係を知る
- 文学的なエピソードを理解する
- 文学理論・文学ジャンルを理解する
- 俳句・短歌などの表現形式を覚える
- 複数の知識を組み合わせて問題を解く

## 2. 対象ユーザー

- 中学受験生（特に難関中学校を受験する小学生）
- 文学史を体系的に学びたい人

特定の学校向けのサイトにはしない。

## 3. 対象分野

日本文学史 / 作家・文学者のプロフィール / 代表作品 / 人物関係 / 文学的エピソード / 文学運動・文学理論 / 文学ジャンル / 俳句・短歌・詩 / 文学史上の年代・出来事

（海外作家も、国籍などのプロフィール知識として必要な範囲で扱う）

## 4. 運営方針：調査対象と公開対象を分ける

| 項目 | 内部調査 | 公開サイト |
|---|---|---|
| 特定学校の名前 | 使用する | **掲載しない** |
| 過去問の年度・出題実績・試験区分 | 管理する | **掲載しない** |
| 出題傾向 | コンテンツ選定に使う | 学校別情報として掲載しない |
| 過去問の問題文・選択肢・解答 | 参照する | **転載しない** |
| 作家・作品・人物関係・用語 | 調査する | 掲載する（独自の文章で） |
| 文学的エピソード | 調査する | 独自に解説する |
| 問題 | — | オリジナルを作成して掲載する |

コンテンツの選定基準は、難関中学の入試傾向の内部調査をもとに決める。公開サイト上では「一般的な中学受験向け文学史サイト」として運営する。

## 5. 学習カテゴリ（コンテンツ設計の基礎となる6分類）

内部調査で確認した出題傾向を、以下の6つの知識カテゴリに整理した。公開サイトのコンテンツ・問題はこの分類に沿って作る。

| # | カテゴリ | 学習内容 | 主に対応するデータ |
|---|---|---|---|
| ① | 作家と作品の識別 | 代表作品、作品と作者の対応、「ある作家の作品ではないもの」の識別、複数作家の作品の区別 | People / Works |
| ② | 時代・年代による識別 | 生没年、活動時代、発表時期、文学運動の成立時期、江戸〜現代の流れ | Eras / Events / Works |
| ③ | 作家のプロフィール | 国籍、出身地、家族関係、親子関係、生没年 | People / Relationships |
| ④ | 人物関係・文学的エピソード | 親子・師弟・交流、文学賞をめぐる出来事、発言や手紙、逸話 | Relationships / Events |
| ⑤ | 文学理論・文学ジャンル | リアリズム、純文学、大衆文学、世界文学、自然主義、浪漫主義、白樺派、無頼派など | Terms |
| ⑥ | 俳句・短歌・表現形式 | 俳句、短歌、自由律俳句、俳人・歌人、俳人同士の関係 | Terms / People |

重視する3点：

1. 作家と作品の対応だけでなく、**国籍・家族関係・人物同士の関係**も必要になる。
2. 年代だけでなく、**リアリズム・純文学などの概念**も対象になる。
3. エピソードや本文中の手掛かりから人物を特定する、**知識と読解を組み合わせた問題**がある。

※ これは確認できた事例の分類であり、出題頻度の統計ではない。

## 7. サイト構成

```
文学の系譜（仮称）
├─ トップページ        サイト紹介・学習カテゴリ・今日の問題・おすすめ
├─ 作家一覧 / 作家詳細   プロフィール・代表作品・人物関係・エピソード
├─ 作品一覧 / 作品詳細   作者・発表時期・ジャンル・あらすじ
├─ 文学史年表          江戸〜現代、作家・作品・運動・文学賞を横断
├─ 人物相関図          親子・師弟・交流・影響・文学賞・同じ文学運動
├─ 文学用語集          文学理論・文学運動・ジャンル・表現形式
└─ 演習問題            暗記・年代・人物関係・エピソード・応用
```

過去問データベースは公開ページに設けない。

### 7-1. 各コンテンツの掲載項目

**作家**：名前（読み）、生没年（西暦）、活動時代、出身地、国籍、代表作品、文学的立場、関係する人物、文学的エピソード、関連用語、関連クイズ

**作品**：作品名、作者、発表時期、ジャンル、あらすじ（独自執筆）、関連作品、関連作家、文学史上の位置付け

**年表**：生没年、代表作品の発表、文学運動、文学賞、文学史上の出来事

**人物相関図**：親子、師弟、文学的交流、影響（敬愛）、文学賞をめぐる関係、同じ文学運動。客観的に確認できる関係のみ掲載し、単なる同時代人を無理に結び付けない。

**文学用語**：意味、成立背景、関連する文学者、関連作品、類似用語との違い、理解度チェック

**演習問題**：

| 形式 | 例 |
|---|---|
| 作家・作品対応 | 『羅生門』の作者は誰か |
| 作品識別 | ある作家の作品ではないものを選ぶ |
| 正誤判定 | プロフィール・人物関係の正誤 |
| 年代 | 文学者を活動時代順に並べる |
| 人物関係 | 親子・師弟・交流 |
| エピソード | 出来事から人物を特定する |
| 文学用語 | リアリズムなどの意味 |
| 応用 | 複数の知識を使って推測する |

**エピソード型**と**応用型**を特に重視する。
