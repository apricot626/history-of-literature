# 01. 企画方針

> このファイルは公開リポジトリに置くため、特定の学校名・過去問の年度・出題実績は記載しません。
> 内部調査の内容は非公開の内部資料で管理します（`internal/`、git管理外）。

## 1. サイトの目的

単なる文学史の暗記サイトではなく、**作家・作品・時代・文学的なつながりを体系的に学べる**サイトを作る。

提供する学習：

- 作家と代表作品を覚える
- 作家の活動時代や文学史上の位置付けを理解する
- 作家同士の関係を知る
- 文学的なエピソードを理解する
- 文学理論・文学ジャンルを理解する
- 俳句・短歌などの表現形式を覚える
- 複数の知識を組み合わせて問題を解く

## 2. 対象ユーザー

- 中学受験生（特に難関中学校を受験する小学生）
- 文学史を体系的に学びたい人

特定の学校向けのサイトにはしない。

## 3. 対象分野

日本文学史 / 作家・文学者のプロフィール / 代表作品 / 人物関係 / 文学的エピソード / 文学運動・文学理論 / 文学ジャンル / 俳句・短歌・詩 / 文学史上の年代・出来事

（海外作家も、国籍などのプロフィール知識として必要な範囲で扱う）

## 4. 運営方針：調査対象と公開対象を分ける

| 項目 | 内部調査 | 公開サイト |
|---|---|---|
| 特定学校の名前 | 使用する | **掲載しない** |
| 過去問の年度・出題実績・試験区分 | 管理する | **掲載しない** |
| 出題傾向 | コンテンツ選定に使う | 学校別情報として掲載しない |
| 過去問の問題文・選択肢・解答 | 参照する | **転載しない** |
| 作家・作品・人物関係・用語 | 調査する | 掲載する（独自の文章で） |
| 文学的エピソード | 調査する | 独自に解説する |
| 問題 | — | オリジナルを作成して掲載する |

コンテンツの選定基準は、難関中学の入試傾向の内部調査をもとに決める。公開サイト上では「一般的な中学受験向け文学史サイト」として運営する。

## 5. 学習カテゴリ（9分類）

内部調査で確認した問題の形式を、次の9つの知識カテゴリに整理した。演習問題・作家ページはこの分類に沿って作る。

| # | カテゴリ | 問題文に示される情報（例） | 必要な知識 | 主なページ |
|---|---|---|---|---|
| 1 | 作家と作品 | 作品名・選択肢 | 作者と作品の対応。代表作以外もふくめ、同じころの作家の作品と見分ける | 作家・作品 |
| 2 | 文学史・年代 | 時代や年代を説明する文章 | 作家・作品の活動時代、江戸〜現代の流れ | 年表 |
| 3 | 作家のプロフィール | 外国の文学者の名前、親族についての説明 | 国籍、親子関係、本名 | 作家 |
| 4 | 作家どうしの関係 | 先生・弟子、敬愛などの説明 | 親子・師弟・敬愛・交流の区別 | 相関図 |
| 5 | 文学のエピソード | 手紙・文学賞などの出来事 | 人物関係と出来事を結び付ける | 作家・年表 |
| 6 | 文学の考え方 | 理念や作品の特徴の説明 | リアリズムなどの意味 | 単語帳 |
| 7 | 文学の種類 | 文学の分類についての説明 | 純文学・大衆文学・世界文学・児童文学など | 単語帳 |
| 8 | 俳句・短歌 | 句や形式の説明 | 定型・自由律・季語・音の数 | 詩歌・単語帳 |
| 9 | 俳人どうしの関係 | 俳人・歌人についての説明 | 良寛と松尾芭蕉など | 詩歌・相関図 |

重視すること：

1. **問題文に書かれている情報と、自分で知っていなければならない情報は違う。**
2. 作品だけでなく、国籍・家族関係・文学賞・エピソードも人物を見分ける手掛かりになる。
3. 複数の知識を組み合わせて人物を推測する問題がある。

### 5-1. 問題の分け方

- **一問一答**：単純な知識問題（作品名→作者、言葉の意味、国籍など）。答えと「覚えておきたい知識」だけを載せる
- **演習問題**：いくつかの知識を組み合わせて考える問題。解説は「必要な知識 → 考え方 → 答え」の順に書く（作り方は別途指定）

作家ページには「覚えておきたいポイント」（その作家について、問題を解くために必要な知識）を載せる。

### 5-2. 人物・作品の選び方

- 人物数・作品数の目標は設定しない。
- 問題に出た知識を理解し、解くために必要な人物だけを採用する。
- 有名だからという理由だけで人物を追加しない。
- 素材文に登場しただけの人物を、直接出題された人物として扱わない。
- 説明に必要なだけの人物（例：芥川賞をつくった菊池寛）は、作家ページを作らず文章の中で名前を出す。
- 設問の原文を確認できていない情報は、断定しない。

## 7. サイト構成

```
文学の系譜（仮称）
├─ トップページ        サイト紹介・学習カテゴリ・今日の問題・おすすめ
├─ 作家一覧 / 作家詳細   プロフィール・代表作品・人物関係・エピソード
├─ 作品一覧 / 作品詳細   作者・発表時期・ジャンル・あらすじ
├─ 文学史年表          江戸〜現代、作家・作品・運動・文学賞を横断
├─ 人物相関図          親子・師弟・交流・影響・文学賞・同じ文学運動
├─ 詩歌                和歌・短歌・連歌・俳諧・俳句・川柳・自由律俳句、有名な句と歌
├─ 海外の作家          国ごとの一覧（基本：人物名→国／標準：代表作／発展：文学者・思想家）。日本の作家ほど重要ではないので別ページ
├─ 単語帳              むずかしい言葉を小学生向けにやさしく説明（文学のグループ・種類・詩のかたち・文学の世界のことば）
├─ 一問一答            単純な知識問題。問題を押すと答えと「覚えておきたい知識」が出る
└─ 演習問題            知識を組み合わせて考える問題。解説は「必要な知識→考え方→答え」（作り方は別途指定）
```

過去問に関するページは公開サイトに設けない。

サイトはHTMLとCSSだけで構成する（データベース・ビルド・JavaScriptなし）。詳細は [02_site-structure.md](02_site-structure.md)。

### 7-1. 各コンテンツの掲載項目

**作家**：覚えておきたいポイント、名前（読み）、生没年（西暦）、活動時代、出身地、国籍、本名、代表作品、グループ・作風、つながりのある人物、文学史の出来事、この作家が出てくる問題

**作品**：作品名、作者、発表時期、ジャンル、あらすじ（独自執筆）、関連作品、関連作家、文学史上の位置付け

**年表**：生没年、代表作品の発表、文学運動、文学賞、文学史上の出来事

**人物相関図**：親子、師弟、文学的交流、影響（敬愛）、文学賞をめぐる関係、同じ文学運動。客観的に確認できる関係のみ掲載し、単なる同時代人を無理に結び付けない。

**単語帳**：ひとことで言うと、くわしい説明、にている言葉とのちがい、関係する作家・作品。本文中のむずかしい言葉（例：反自然主義、選評、門下生）は点線の下線付きリンクにして、単語帳の説明へ移動できるようにする

**演習問題**：

| 形式 | 例 |
|---|---|
| 作家・作品対応 | 『羅生門』の作者は誰か |
| 作品識別 | ある作家の作品ではないものを選ぶ |
| 正誤判定 | プロフィール・人物関係の正誤 |
| 年代 | 文学者を活動時代順に並べる |
| 人物関係 | 親子・師弟・交流 |
| エピソード | 出来事から人物を特定する |
| 文学用語 | リアリズムなどの意味 |
| 応用 | 複数の知識を使って推測する |

**エピソード型**と**応用型**を特に重視する。
