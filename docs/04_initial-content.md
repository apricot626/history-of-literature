## 4. 人物関係・エピソードの要確認リスト

- [ ] 太宰治が芥川龍之介の名をノートに書き連ねた話の出典
- [ ] 第1回芥川賞での川端康成の選評の該当部分と、太宰治「川端康成へ」の掲載誌
- [ ] 漱石・鷗外を「ともに反自然主義」とする扱い（個人的な交流ではなく、文学的な立場として）
- [ ] 自由律俳句の例句（山頭火・放哉）の表記を出典で確認
- [ ] 『或る朝』の発表年、『鳥の涙』の発表年とあらすじ

- 良寛 → 松尾芭蕉（敬愛したとされる）：根拠を確認するまで載せない
