# 03. コンテンツ制作ガイドライン

## 1. 著作権

学校名を載せないことと、著作権上の問題がなくなることは別。公開サイトは**独自教材**として作る。

- 過去問の問題文・選択肢・解説を転載しない（問題は形式を参考にしても、文章・選択肢の組み合わせ・解説はオリジナルで作る）
- 小説本文や現代作品の長い引用をしない
- 作家プロフィールは複数の資料を参考に、独自の文章で書く
- 作品のあらすじも独自に書く
- 既存サイト・参考書の人物相関図・年表・文章を流用しない
- 俳句・短歌など短い作品の引用は、作者の没後70年を過ぎているかを確認し、出典を明記する

## 2. 事実確認

- 生没年・発表年・人物関係は**2つ以上の信頼できる資料**で確認してから `checked` にする
- 発表年は「初出（雑誌掲載）」と「単行本刊行」がずれることがある。どちらを採るかを `year_note` に書く
- 諸説ある内容は「〜とされる」と書き、`verification.note` に説明を残す
- 誤った人物関係や年代を載せない。迷ったら載せない

## 3. 人物関係の掲載基準

掲載する：

- 親子・兄弟などの家族関係
- 師弟関係（門下、弟子入り、指導）
- 資料で確認できる交流・友人関係・同人関係
- 敬愛・影響（本人の文章や発言など根拠があるもの）
- 文学賞などをめぐる具体的な出来事
- 同じ文学運動・流派への所属

掲載しない：

- 同時代に活動していただけの関係
- 根拠の弱い噂・俗説

## 4. 文章のトーン

- 対象は小学生。常用漢字外にはふりがな（読み）を付ける前提で書く
- 1つの説明は短く、結論から書く
- 作家の私生活の出来事（自殺・心中・病気など）は、学習に必要な範囲で事実のみを簡潔に書く

## 5. 問題作成

- 学習カテゴリ①〜⑥のどれかに必ず分類する
- エピソード型・応用型を重視する：複数の手掛かり（時代・関係・作品）を組み合わせて1人に絞り込める作りにする
- 誤答の選択肢も実在の作家・作品を使い、「なぜ違うか」を解説に書く
- 解説から作家・作品・用語のページへリンクできるよう、関連IDを必ず付ける
