# 文学の系譜（仮称）

作家・作品・時代・人物関係から、日本の文学史を**線と面で**学ぶ学習サイトです。読者は**中学受験をする小学生**です。

HTMLとCSSだけで作る静的サイトです。データベース、ビルド、JavaScriptは使いません。`index.html` をブラウザで開けばそのまま表示できます。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | トップページ（学習コンテンツ・今日の問題・つながりの例） |
| `authors.html` | 作家一覧（時代別。覚えておきたいポイント・プロフィール・代表作品・つながり） |
| `works.html` | 作品一覧（時代別。作者・発表年・ジャンル・あらすじ） |
| `timeline.html` | 文学史年表（江戸〜現代） |
| `relations.html` | 人物相関図（インラインSVG＋関係の説明） |
| `poetry.html` | 詩歌（詩のかたちの比較表・流れ・有名な句と歌） |
| `foreign.html` | 海外の作家・文学者（国ごと・代表作・文学者の3レベル） |
| `glossary.html` | 単語帳（むずかしい言葉を小学生向けにやさしく説明） |
| `ichimon.html` | 一問一答（単純な知識の確認。問題を押すと答えと知識が出る） |
| `quiz.html` | 演習問題（知識を組み合わせて考える問題。解説は「必要な知識→考え方→答え」） |
| `images/authors/` | 作家の写真（著作権の保護期間が終わったものだけ。出典は作家一覧の「写真について」） |
| `style.css` | 共通スタイル（ライト／ダークモード対応） |
| `docs/` | 企画・ページ構成・制作ルール・コンテンツ一覧 |

## 公開情報と内部情報の分離（最重要ルール）

このリポジトリは**公開**されています。以下は絶対にコミットしないでください。

- 特定の学校名
- 過去問の年度・出題実績・試験区分
- 過去問の問題文・選択肢・解答・解説

内部調査資料は `internal/`（`.gitignore` 済み）またはリポジトリ外の非公開の場所で管理します。
