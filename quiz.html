文学史・年代

文学史・年代年代★★☆

問1

次の人物を、生まれた年の早い順に並べたとき、3番目になるのはだれですか。

  1. 太宰治
  2. 松尾芭蕉
  3. 夏目漱石
  4. 三島由紀夫
答えと考え方を見る

  1. 必要な知識

    • 松尾芭蕉（1644年生まれ・江戸時代）
    • 夏目漱石（1867年生まれ・明治に活躍）
    • 太宰治（1909年生まれ・昭和に活躍）
    • 三島由紀夫（1925年生まれ・昭和に活躍）

  2. 考え方

    活躍した時代で大まかに並べ（江戸→明治→昭和）、同じ昭和の太宰と三島は生まれた年で比べる。芭蕉→漱石→太宰→三島の順。

  3. 答え

    ア　太宰治

くわしく：太宰治、松尾芭蕉、夏目漱石、三島由紀夫

作家どうしの関係

作家どうしの関係エピソード★★☆

問2

次の手掛かりすべてにあてはまる作家はだれですか。
・イギリスに留学したことがある。
・門下生の芥川龍之介が書いた『鼻』を、手紙で大絶賛した。
・四国の中学校に数学の先生としてやってきた青年の物語を書いた。

  1. 森鷗外
  2. 夏目漱石
  3. 志賀直哉
  4. 川端康成
答えと考え方を見る

  1. 必要な知識

    • 夏目漱石はイギリスに留学した
    • 芥川龍之介は漱石の門下生で、『鼻』を漱石にほめられた
    • 四国の中学校が舞台の物語は『坊っちゃん』

  2. 考え方

    三つの手掛かりのどれからでも漱石にたどり着ける。森鷗外も留学しているが、行き先はドイツで、芥川の先生でもない。

  3. 答え

    イ　夏目漱石

くわしく：夏目漱石、芥川龍之介、森鷗外、『鼻』、『坊っちゃん』

作家どうしの関係人物★★☆

問3

夏目漱石の学生時代からの親友で、俳句と短歌を新しくし、「俳句」というよび方を広めた人物はだれですか。

  1. 正岡子規
  2. 松尾芭蕉
  3. 種田山頭火
  4. 菊池寛
答えと考え方を見る

  1. 必要な知識

    • 正岡子規は漱石の親友で、漱石は子規から俳句を教わった
    • 子規は「写生」を大切にして、俳句と短歌を新しくした
    • 松尾芭蕉は江戸時代の俳人
    • 種田山頭火は自由律俳句の俳人
    • 菊池寛は芥川龍之介の友人

  2. 考え方

    芭蕉は江戸時代の人なので、明治の漱石の親友にはなれない。山頭火は自由律俳句、菊池寛は芥川の友人。残るのは正岡子規。

  3. 答え

    ア　正岡子規

くわしく：正岡子規、夏目漱石、松尾芭蕉、種田山頭火、菊池寛、写生

文学のエピソード

文学のエピソードエピソード★★★

問4

次の手掛かりすべてにあてはまる作家はだれですか。
・昭和に活躍した。
・第1回芥川賞の候補になったが、受賞できなかった。
・娘も小説家になった。

  1. 太宰治
  2. 川端康成
  3. 芥川龍之介
  4. 三島由紀夫
答えと考え方を見る

  1. 必要な知識

    • 第1回芥川賞（1935年）で、太宰治は候補になったが受賞できなかった
    • 川端康成はそのときの選考委員
    • 芥川龍之介は芥川賞ができる前（1927年）に亡くなっている
    • 太宰治の娘・津島佑子は小説家

  2. 考え方

    選択肢を一つずつ消していく。川端は賞を選ぶ側（選考委員）、芥川は賞の名前になった人で、賞ができたときにはすでに亡くなっている。三島は1925年生まれで、1935年にはまだ10歳。残るのは太宰治。

  3. 答え

    ア　太宰治

くわしく：太宰治、川端康成、芥川龍之介、三島由紀夫、津島佑子、芥川賞・直木賞、選考委員・選評

文学のエピソード応用★★★

問5

ある作家について、次の手掛かりがあります。
① この作家の名前がついた文学賞がある。
② その賞をつくったのは、作家の友人だった。
③ 古い物語集の話を題材にした短編を多く書いた。
この作家の作品を一つ選びなさい。

  1. 『鼻』
  2. 『こころ』
  3. 『斜陽』
  4. 『雪国』
答えと考え方を見る

  1. 必要な知識

    • 芥川賞は、友人の菊池寛が芥川龍之介の名前をつけてつくった
    • 芥川は『今昔物語集』などを題材にした短編を書いた
    • 『こころ』は漱石、『斜陽』は太宰、『雪国』は川端の作品

  2. 考え方

    まず手掛かりから作家（芥川龍之介）を決め、次にその作家の作品を選ぶ、二段階の問題。作家がわかっても、作品を取りちがえないように注意する。

  3. 答え

    ア　『鼻』

くわしく：芥川龍之介、菊池寛、『鼻』、『こころ』、『斜陽』、『雪国』、芥川賞・直木賞

俳人どうしの関係

俳人どうしの関係人物★★★

問6

次の手掛かりすべてにあてはまる俳人はだれですか。
・江戸時代の前半に活躍した。
・弟子の曾良と、東北・北陸を歩いて旅した。
・江戸時代の後半の僧・良寛が、深く尊敬したとされる。

  1. 松尾芭蕉
  2. 小林一茶
  3. 与謝蕪村
  4. 正岡子規
答えと考え方を見る

  1. 必要な知識

    • 松尾芭蕉（1644〜1694年）は弟子の曾良と旅をして『おくのほそ道』を書いた
    • 良寛（1758〜1831年）は芭蕉を尊敬していたとされる
    • 与謝蕪村は江戸時代の中ごろ、小林一茶は江戸時代の後半、正岡子規は明治時代の俳人

  2. 考え方

    曾良との旅は『おくのほそ道』のこと。また、良寛より前の時代の人でなければ、良寛が尊敬することはできない。時代を考えると、明治の正岡子規はあてはまらない。

  3. 答え

    ア　松尾芭蕉

くわしく：松尾芭蕉、良寛、『おくのほそ道（奥の細道）』、俳人・歌人、敬愛
