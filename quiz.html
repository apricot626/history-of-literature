問1

次の手掛かりすべてにあてはまる作家はだれですか。
・イギリスに留学したことがある。
・門下生の芥川龍之介が書いた『鼻』を、手紙で大絶賛した。
・四国の中学校に数学の先生としてやってきた青年の物語を書いた。

  1. 森鷗外
  2. 夏目漱石
  3. 志賀直哉
  4. 川端康成
答えと考え方を見る

  1. 必要な知識

    • 夏目漱石はイギリスに留学した
    • 芥川龍之介は漱石の門下生で、『鼻』を漱石にほめられた
    • 四国の中学校が舞台の物語は『坊っちゃん』

  2. 考え方

    三つの手掛かりのどれからでも漱石にたどり着ける。森鷗外も留学しているが、行き先はドイツで、芥川の先生でもない。手掛かりが複数あるときは、いちばん自信のあるものから候補をしぼろう。

  3. 答え

    イ　夏目漱石

覚えておくこと作家の代表作だけでなく、留学先・弟子・エピソードもセットで覚える。

くわしく：夏目漱石、芥川龍之介、森鷗外、『鼻』、『坊っちゃん』

問2

次の手掛かりすべてにあてはまる作家はだれですか。
・昭和に活躍した。
・第1回芥川賞の候補になったが、受賞できなかった。
・娘も小説家になった。

  1. 太宰治
  2. 川端康成
  3. 芥川龍之介
  4. 三島由紀夫
答えと考え方を見る

  1. 必要な知識

    • 第1回芥川賞（1935年）で、太宰治は候補になったが受賞できなかった
    • 川端康成はそのときの選考委員
    • 芥川龍之介は芥川賞ができる前（1927年）に亡くなっている
    • 太宰治の娘・津島佑子は小説家

  2. 考え方

    選択肢を一つずつ消していく。川端は賞を選ぶ側、芥川は賞の名前になった人で、賞ができたときにはすでに亡くなっている。三島は1925年生まれで、1935年にはまだ10歳。残るのは太宰治。

  3. 答え

    ア　太宰治

覚えておくこと文学賞をめぐる出来事は、「だれが選ぶ側で、だれが候補だったか」まで覚える。

くわしく：太宰治、川端康成、芥川龍之介、三島由紀夫、津島佑子、芥川賞・直木賞、選考委員・選評

問3

次の手掛かりすべてにあてはまる俳人はだれですか。
・江戸時代の前半に活躍した。
・弟子の曾良と、東北・北陸を歩いて旅した。
・江戸時代の後半の僧・良寛が、深く尊敬したとされる。

  1. 松尾芭蕉
  2. 小林一茶
  3. 与謝蕪村
  4. 正岡子規
答えと考え方を見る

  1. 必要な知識

    • 松尾芭蕉（1644〜1694年）は弟子の曾良と旅をして『おくのほそ道』を書いた
    • 良寛（1758〜1831年）は芭蕉を尊敬していたとされる
    • 与謝蕪村は江戸時代の中ごろ、小林一茶は江戸時代の後半、正岡子規は明治時代の俳人

  2. 考え方

    曾良との旅は『おくのほそ道』のこと。また、良寛より前の時代の人でなければ、良寛が尊敬することはできない。時代の順番も手掛かりになる。

  3. 答え

    ア　松尾芭蕉

覚えておくこと人物どうしのつながりは、どちらが前の時代の人かも確かめておく。

くわしく：松尾芭蕉、良寛、『おくのほそ道（奥の細道）』、敬愛

問4

次の手掛かりすべてにあてはまる人物はだれですか。
・夏目漱石の学生時代からの親友。
・見たままを描く「写生」を大切にした。
・「俳句」というよび方を広めた。

  1. 正岡子規
  2. 松尾芭蕉
  3. 種田山頭火
  4. 菊池寛
答えと考え方を見る

  1. 必要な知識

    • 正岡子規は漱石の親友で、写生を唱え、俳句と短歌を新しくした
    • 松尾芭蕉は江戸時代の俳人
    • 種田山頭火は自由律俳句の俳人
    • 菊池寛は芥川龍之介の友人

  2. 考え方

    芭蕉は江戸時代の人なので、明治の漱石の親友にはなれない。山頭火は自由律俳句、菊池寛は芥川の友人。残るのは正岡子規。

  3. 答え

    ア　正岡子規

覚えておくこと「親友」「師弟」などのつながりは、相手の作家とセットで覚える。

くわしく：正岡子規、夏目漱石、松尾芭蕉、種田山頭火、菊池寛、写生

  4. 志賀直哉

問8

次の手掛かりすべてにあてはまる人物はだれですか。
・明治から昭和にかけて活躍した歌人。
・歌集『みだれ髪』で、恋の気持ちを情熱的にうたった。
・詩「君死にたまふことなかれ」を書いた。

  1. 与謝野晶子
  2. 島崎藤村
  3. 正岡子規
  4. 津島佑子
答えと考え方を見る

  1. 必要な知識

    • 与謝野晶子は浪漫主義の短歌を代表する歌人
    • 歌集『みだれ髪』、詩「君死にたまふことなかれ」

  2. 考え方

    『みだれ髪』は歌集。島崎藤村も浪漫主義の詩人だが、代表作は詩集『若菜集』。

  3. 答え

    ア　与謝野晶子

覚えておくこと浪漫主義の詩歌は「晶子＝歌集『みだれ髪』」「藤村＝詩集『若菜集』」で区別する。

くわしく：与謝野晶子、島崎藤村、『みだれ髪』、『若菜集』、浪漫主義

問11

小説『浮雲』を書いた作家はだれですか。

  1. 坪内逍遥
  2. 二葉亭四迷
  3. 森鷗外
  4. 夏目漱石
答えと考え方を見る

  1. 必要な知識

    • 『浮雲』は二葉亭四迷が言文一致で書いた小説
    • 坪内逍遥は評論『小説神髄』でリアリズムを唱えた人で、二葉亭を後押しした

  2. 考え方

    坪内逍遥と二葉亭四迷は、どちらもリアリズムに関係するのでまぎらわしい。「考えを唱えた人（逍遥）」と「それを作品にした人（二葉亭）」を区別する。

  3. 答え

    イ　二葉亭四迷

覚えておくこと関係の深い二人は、それぞれの作品を取りちがえやすい。セットで区別して覚える。

くわしく：二葉亭四迷、坪内逍遥、『浮雲』、『小説神髄』、リアリズム（写実主義）、言文一致

問12

小説『破戒』を書いた作家はだれですか。

  1. 田山花袋
  2. 島崎藤村
  3. 志賀直哉
  4. 森鷗外
答えと考え方を見る

  1. 必要な知識

    • 『破戒』は島崎藤村の小説で、自然主義の代表作
    • 田山花袋の代表作は『蒲団』（同じく自然主義）

  2. 考え方

    藤村と花袋は、どちらも自然主義の代表的な作家で、友人どうし。「破戒＝藤村」「蒲団＝花袋」をセットで覚えておけば迷わない。

  3. 答え

    イ　島崎藤村

覚えておくこと同じグループの作家は、代表作を一つずつ対にして覚える。

くわしく：島崎藤村、田山花袋、『破戒』、『蒲団』、自然主義

次のＡ〜Ｃの作品を書いた作家の国の組み合わせとして、正しいものを選びなさい。
Ａ『罪と罰』　Ｂ『レ・ミゼラブル』　Ｃ『ハムレット』

  1. Ａ ロシア　Ｂ フランス　Ｃ イギリス
  2. Ａ フランス　Ｂ ロシア　Ｃ イギリス
  3. Ａ ロシア　Ｂ イギリス　Ｃ フランス
  4. Ａ イギリス　Ｂ フランス　Ｃ ロシア
答えと考え方を見る

  1. 必要な知識

    • 『罪と罰』はドストエフスキー（ロシア）
    • 『レ・ミゼラブル』はユーゴー（フランス）
    • 『ハムレット』はシェイクスピア（イギリス）

  2. 考え方

    作品→作者→国の順に考える。

  3. 答え

    ア　Ａ ロシア　Ｂ フランス　Ｃ イギリス

覚えておくこと海外の作品は「作品・作者・国」の三つをセットで覚える。

くわしく：ドストエフスキー、ヴィクトル・ユーゴー、ウィリアム・シェイクスピア

問80

ある作家について、次の手掛かりがあります。
① 雑誌『白樺』をつくった仲間の一人。
② むだのない正確な文章で、「小説の神様」とよばれた。
この作家の作品を一つ選びなさい。

  1. 『城の崎にて』
  2. 『友情』
  3. 『伊豆の踊子』
  4. 『蒲団』
答えと考え方を見る

  1. 必要な知識

    • 手掛かりにあてはまるのは志賀直哉
    • 『城の崎にて』は志賀直哉の作品
    • 『友情』は同じ白樺派の武者小路実篤

  2. 考え方

    まず人物を決め（①だけでは武者小路実篤も候補。②で志賀直哉）、次に作品を選ぶ二段階の問題。

  3. 答え

    ア　『城の崎にて』

覚えておくこと人物を特定したあと、その人物の作品まで答えられるようにする。

くわしく：志賀直哉、武者小路実篤、『城の崎にて』、『友情』、白樺派
