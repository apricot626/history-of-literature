問1

『走れメロス』を書いた作家はだれですか。

  1. 太宰治
  2. 芥川龍之介
  3. 川端康成
  4. 志賀直哉
答えと解説を見る

答え：ア

『走れメロス』は太宰治が1940年に発表した短編小説です。親友との約束を守るために走り続ける青年を描いています。

くわしく：太宰治、『走れメロス』

作家と作品作品の識別★☆☆

問2

芥川龍之介の作品ではないものを一つ選びなさい。

  1. 『羅生門』
  2. 『鼻』
  3. 『蜘蛛の糸』
  4. 『坊っちゃん』
答えと解説を見る

答え：エ

『坊っちゃん』は夏目漱石の作品です。芥川龍之介は漱石の門下生で、『鼻』は漱石に絶賛されました。師弟の作品を取り違えないようにしましょう。

くわしく：芥川龍之介、夏目漱石、『羅生門』、『鼻』、『蜘蛛の糸』、『坊っちゃん』

人物関係・エピソードエピソード★★☆

問3

次の手掛かりすべてにあてはまる作家はだれですか。
・明治から大正にかけて活躍した。
・俳人の正岡子規とは学生時代からの親友だった。
・門下生の一人に芥川龍之介がいる。

  1. 森鷗外
  2. 夏目漱石
  3. 島崎藤村
  4. 坪内逍遥
答えと解説を見る

答え：イ

夏目漱石は正岡子規の親友で、子規から俳句を学びました。また、芥川龍之介の『鼻』を絶賛し、作家としての出発を後押ししました。

くわしく：夏目漱石、正岡子規、芥川龍之介

俳句・短歌用語★☆☆

問4

五・七・五の決まった音数や季語にとらわれず、自由なリズムで詠む俳句を何といいますか。

  1. 自由律俳句
  2. 川柳
  3. 短歌
  4. 連歌
答えと解説を見る

答え：ア

自由律俳句は荻原井泉水が唱え、種田山頭火や尾崎放哉が代表的な作品を残しました。川柳は五・七・五の形を守る点で自由律俳句とは異なります。

くわしく：荻原井泉水、種田山頭火、尾崎放哉、自由律俳句、俳句

時代・年代年代★★☆

問5

次の人物を生まれた年の早い順に並べたとき、3番目になるのはだれですか。

  1. 太宰治
  2. 松尾芭蕉
  3. 夏目漱石
  4. 三島由紀夫
答えと解説を見る

答え：ア

松尾芭蕉（1644年）→夏目漱石（1867年）→太宰治（1909年）→三島由紀夫（1925年）の順です。江戸・明治・昭和と、活躍した時代も合わせて覚えましょう。

くわしく：太宰治、松尾芭蕉、夏目漱石、三島由紀夫

文学用語用語★★☆

問6

白樺派の作家を二人選びなさい。

  1. 志賀直哉
  2. 武者小路実篤
  3. 太宰治
  4. 田山花袋
答えと解説を見る

答え：ア・イ

志賀直哉と武者小路実篤は、1910年に雑誌『白樺』を創刊した仲間です。太宰治は無頼派、田山花袋は自然主義の作家です。

くわしく：志賀直哉、武者小路実篤、太宰治、田山花袋、白樺派、無頼派、自然主義文学

人物関係・エピソード応用★★★

問7

ある作家について、次の手掛かりがあります。
① この作家の名前がついた文学賞がある。
② その賞をつくったのは、作家の友人だった。
③ 古典の説話を題材にした短編を多く書いた。
この作家の作品を一つ選びなさい。

  1. 『鼻』
  2. 『こころ』
  3. 『斜陽』
  4. 『雪国』
答えと解説を見る

答え：ア

手掛かりにあてはまるのは芥川龍之介です。芥川賞は、友人の菊池寛が芥川の死後につくりました。『こころ』は夏目漱石、『斜陽』は太宰治、『雪国』は川端康成の作品です。

くわしく：芥川龍之介、菊池寛、『鼻』、『こころ』、『斜陽』、『雪国』
