演習問題

覚えた知識を使って解いてみましょう。答えは「答えと解き方を見る」を押すと出てきます。★の数はむずかしさの目安です。

解き方の4つのステップ

  1. 手掛かり：問題文に何が書かれているかを読み取る
  2. 知識：自分が知っていなければならないことを思い出す
  3. 考え方：手掛かりと知識を結び付けて、答えをしぼる
  4. 答え：最後に答えを決める

作家と作品作家・作品★☆☆

問1

『走れメロス』を書いた作家はだれですか。

  1. 太宰治
  2. 芥川龍之介
  3. 川端康成
  4. 志賀直哉
答えと解き方を見る

  1. 問題文の手掛かり

    • 作品名『走れメロス』

  2. 必要な知識

    • 『走れメロス』は太宰治の短編小説（1940年）
    • 太宰治の代表作には『斜陽』『人間失格』もある

  3. 考え方

    作品名から作者を思い出す。ほかの三人の代表作（芥川『羅生門』、川端『雪国』、志賀『城の崎にて』）と取りちがえないようにする。

  4. 答え

    ア　太宰治

くわしく：太宰治、『走れメロス』

問2

芥川龍之介の作品ではないものを一つ選びなさい。

  1. 『羅生門』
  2. 『鼻』
  3. 『蜘蛛の糸』
  4. 『坊っちゃん』
答えと解き方を見る

  1. 問題文の手掛かり

    • 「芥川龍之介の作品ではないもの」を選ぶ

  2. 必要な知識

    • 芥川龍之介の代表作は『羅生門』『鼻』『蜘蛛の糸』
    • 『坊っちゃん』は夏目漱石の作品
    • 芥川は漱石の門下生

  3. 考え方

    選択肢を一つずつ確かめ、芥川の作品を消していく。残った『坊っちゃん』の作者は漱石。先生と弟子の作品はまぎらわしいので注意する。

  4. 答え

    エ　『坊っちゃん』

くわしく：芥川龍之介、夏目漱石、『羅生門』、『鼻』、『蜘蛛の糸』、『坊っちゃん』

問3

夏目漱石の「前期三部作」は、『三四郎』『それから』と、もう一つは何ですか。

  1. 『門』
  2. 『明暗』
  3. 『こころ』
  4. 『坊っちゃん』
答えと解き方を見る

  1. 問題文の手掛かり

    • 夏目漱石の「前期三部作」
    • 『三四郎』『それから』に続く作品

  2. 必要な知識

    • 前期三部作は『三四郎』『それから』『門』
    • 後期三部作は『彼岸過迄』『行人』『こころ』
    • 『明暗』は漱石が亡くなったため未完に終わった最後の作品

  3. 考え方

    『こころ』は後期三部作、『明暗』は最後の未完の作品、『坊っちゃん』は三部作に入らない。代表作だけでなく、三部作のまとまりで覚えておくと区別しやすい。

  4. 答え

    ア　『門』

くわしく：夏目漱石、『三四郎』、『それから』、『門』、『明暗』、『こころ』、三部作

問4

次の文の（　）にあてはまる時代を選びなさい。
「松尾芭蕉が弟子と東北・北陸を旅して『おくのほそ道』を書いたのは、（　）時代のことである。」

  1. 平安
  2. 江戸
  3. 明治
  4. 昭和
答えと解き方を見る

  1. 問題文の手掛かり

    • 松尾芭蕉
    • 『おくのほそ道』の旅

  2. 必要な知識

    • 松尾芭蕉は1644〜1694年の人
    • 『おくのほそ道』の旅は1689年
    • 江戸時代は1603〜1868年

  3. 考え方

    芭蕉が生きた年が、どの時代にあたるかを考える。1600年代の終わりは江戸時代の前半。

  4. 答え

    イ　江戸

くわしく：松尾芭蕉、『おくのほそ道（奥の細道）』

文学史・年代年代★★☆

問5

次の人物を、生まれた年の早い順に並べたとき、3番目になるのはだれですか。

  1. 太宰治
  2. 松尾芭蕉
  3. 夏目漱石
  4. 三島由紀夫
答えと解き方を見る

  1. 問題文の手掛かり

    • 四人の人物を「生まれた年の早い順」に並べる

  2. 必要な知識

    • 松尾芭蕉（1644年生まれ・江戸時代）
    • 夏目漱石（1867年生まれ・明治に活躍）
    • 太宰治（1909年生まれ・昭和に活躍）
    • 三島由紀夫（1925年生まれ・昭和に活躍）

  3. 考え方

    活躍した時代で大まかに並べ（江戸→明治→昭和）、同じ昭和の太宰と三島は生まれた年で比べる。芭蕉→漱石→太宰→三島の順。

  4. 答え

    ア　太宰治

くわしく：太宰治、松尾芭蕉、夏目漱石、三島由紀夫

夏目漱石が留学した国はどこですか。

  1. イギリス
  2. ドイツ
  3. フランス
  4. アメリカ
答えと解き方を見る

  1. 問題文の手掛かり

    • 夏目漱石
    • 留学した国

  2. 必要な知識

    • 夏目漱石は英語の先生で、イギリスに留学した
    • 森鷗外は陸軍の軍医としてドイツに留学した（『舞姫』の舞台もドイツ）

  3. 考え方

    漱石は「英語の先生」だったことを思い出すと、イギリスとわかる。同じ明治の文豪・森鷗外の留学先（ドイツ）と取りちがえないようにする。

  4. 答え

    ア　イギリス

くわしく：夏目漱石、森鷗外、『舞姫』

次の手掛かりすべてにあてはまる作家はだれですか。
・イギリスに留学したことがある。
・門下生の芥川龍之介が書いた『鼻』を、手紙で大絶賛した。
・四国の中学校に数学の先生としてやってきた青年の物語を書いた。

  1. 森鷗外
  2. 夏目漱石
  3. 志賀直哉

    • 芥川龍之介の先生
    • 四国の中学校が舞台の物語の作者

  2. 必要な知識

    • 夏目漱石はイギリスに留学した
    • 芥川龍之介は漱石の門下生で、『鼻』を漱石にほめられた
    • 四国の中学校が舞台の物語は『坊っちゃん』

  3. 考え方

作家どうしの関係人物★★☆

問9

夏目漱石の学生時代からの親友で、俳句と短歌を新しくし、「俳句」というよび方を広めた人物はだれですか。

  1. 正岡子規
  2. 松尾芭蕉
  3. 種田山頭火
  4. 菊池寛
答えと解き方を見る

  1. 問題文の手掛かり

    • 夏目漱石の学生時代からの親友
    • 俳句と短歌を新しくした
    • 「俳句」というよび方を広めた

  2. 必要な知識

    • 正岡子規は漱石の親友で、漱石は子規から俳句を教わった
    • 子規は「写生」を大切にして、俳句と短歌を新しくした
    • 松尾芭蕉は江戸時代の俳人
    • 種田山頭火は自由律俳句の俳人
    • 菊池寛は芥川龍之介の友人

  3. 考え方

    芭蕉は江戸時代の人なので、明治の漱石の親友にはなれない。山頭火は自由律俳句、菊池寛は芥川の友人。残るのは正岡子規。

  4. 答え

    ア　正岡子規

くわしく：正岡子規、夏目漱石、松尾芭蕉、種田山頭火、菊池寛、写生

文学のエピソード

文学のエピソードエピソード★★★

問10

次の手掛かりすべてにあてはまる作家はだれですか。
・昭和に活躍した。
・第1回芥川賞の候補になったが、受賞できなかった。
・娘も小説家になった。

  1. 太宰治
  2. 川端康成
  3. 芥川龍之介
  4. 三島由紀夫
答えと解き方を見る

  1. 問題文の手掛かり

    • 昭和の作家
    • 第1回芥川賞の候補で、受賞できなかった
    • 娘も小説家

  2. 必要な知識

    • 第1回芥川賞（1935年）で、太宰治は候補になったが受賞できなかった
    • 川端康成はそのときの選考委員
    • 芥川龍之介は芥川賞ができる前（1927年）に亡くなっている
    • 太宰治の娘・津島佑子は小説家

  3. 考え方

    選択肢を一つずつ消していく。川端は賞を選ぶ側（選考委員）、芥川は賞の名前になった人で、賞ができたときにはすでに亡くなっている。三島は1925年生まれで、1935年にはまだ10歳。残るのは太宰治。

  4. 答え

    ア　太宰治

くわしく：太宰治、川端康成、芥川龍之介、三島由紀夫、津島佑子、芥川賞・直木賞、選考委員・選評

文学のエピソード応用★★★

問11

ある作家について、次の手掛かりがあります。
① この作家の名前がついた文学賞がある。
② その賞をつくったのは、作家の友人だった。
③ 古い物語集の話を題材にした短編を多く書いた。
この作家の作品を一つ選びなさい。

  1. 『鼻』
  2. 『こころ』
  3. 『斜陽』
  4. 『雪国』
答えと解き方を見る

  1. 問題文の手掛かり

    • 名前がついた文学賞がある
    • 賞をつくったのは友人
    • 古い物語集が題材の短編

  2. 必要な知識

    • 芥川賞は、友人の菊池寛が芥川龍之介の名前をつけてつくった
    • 芥川は『今昔物語集』などを題材にした短編を書いた
    • 『こころ』は漱石、『斜陽』は太宰、『雪国』は川端の作品

  3. 考え方

    まず手掛かりから作家（芥川龍之介）を決め、次にその作家の作品を選ぶ、二段階の問題。作家がわかっても、作品を取りちがえないように注意する。

  4. 答え

    ア　『鼻』

くわしく：芥川龍之介、菊池寛、『鼻』、『こころ』、『斜陽』、『雪国』、芥川賞・直木賞

文学の考え方

文学の考え方言葉の意味★★☆

問12

「リアリズム（写実主義）」の考え方として、もっとも正しいものを選びなさい。

  1. 現実の人間や世の中を、ありのままに写そうとする。
  2. 自分の気持ちや夢を、自由に熱く表現しようとする。
  3. よい人がむくわれ、悪い人がこらしめられる話で、教えを伝えようとする。
  4. 決まった音の数にしばられず、自由なリズムでよむ。
答えと解き方を見る

  1. 問題文の手掛かり

    • 「リアリズム（写実主義）」の考え方

  2. 必要な知識

    • リアリズムは、現実をありのままに写そうとする考え方
    • イは浪漫主義の考え方
    • ウは、リアリズムが広まる前の小説に多かった考え方
    • エは自由律俳句の説明

  3. 考え方

    「写実」の「写」は、うつす、「実」は、本当のこと。言葉の意味から考えると、本当のことをそのまま写す、という意味になる。

  4. 答え

    ア　現実の人間や世の中を、ありのままに写そうとする。

くわしく：リアリズム（写実主義）、浪漫主義、自由律俳句

問13

評論『小説神髄』で、「小説は、人の心や世の中をありのままに写すべきだ」と唱えた人物はだれですか。

  1. 坪内逍遥
  2. 二葉亭四迷
  3. 森鷗外
  4. 正岡子規
答えと解き方を見る

  1. 問題文の手掛かり

    • 評論『小説神髄』
    • 人の心や世の中をありのままに写す（リアリズム）

  2. 必要な知識

    • 坪内逍遥が『小説神髄』でリアリズム（写実主義）を唱えた
    • 二葉亭四迷は、その考えを小説『浮雲』で実際の作品にした
    • 正岡子規も「写生」を唱えたが、俳句・短歌の話

  3. 考え方

芥川賞が主に贈られるのは、どの種類の文学ですか。

  1. 純文学
  2. 大衆文学
  3. 児童文学
  4. 世界文学
答えと解き方を見る

  1. 問題文の手掛かり

    • 芥川賞が贈られる文学の種類

  2. 必要な知識

    • 芥川賞は主に純文学の作品に贈られる
    • 直木賞は主に大衆文学の作品に贈られる

問15

国や言葉のちがいをこえて世界中で読まれ、おたがいに影響し合う文学のことを、何といいますか。

  2. 純文学
  3. 大衆文学
  4. 私小説

  1. 問題文の手掛かり

    • 世界中で読まれ、影響し合う

  2. 必要な知識

俳句・短歌

俳句・短歌詩のかたち★☆☆

問16

五・七・五の決まった音数や季語にとらわれず、自由なリズムでよむ俳句を何といいますか。

  1. 自由律俳句
  2. 川柳
  3. 短歌
  4. 連歌
答えと解き方を見る

  1. 問題文の手掛かり

    • 五・七・五や季語にとらわれない
    • 自由なリズムの俳句

  2. 必要な知識

    • 自由律俳句は、荻原井泉水が始め、種田山頭火や尾崎放哉が有名
    • 川柳は五・七・五の形を守る
    • 短歌は五・七・五・七・七
    • 連歌は何人かで句をつなげる

  3. 考え方

    「自由律」は「自由なリズム」という意味。ほかの三つは、どれも音の数の決まりがある。

  4. 答え

    ア　自由律俳句

くわしく：荻原井泉水、種田山頭火、尾崎放哉、自由律俳句、川柳、短歌、連歌

問17

五・七・五・七・七の三十一音でつくる詩を何といいますか。

  1. 俳句
  2. 短歌
  3. 川柳
  4. 自由律俳句
答えと解き方を見る

  1. 問題文の手掛かり

    • 五・七・五・七・七
    • 三十一音

  2. 必要な知識

    • 短歌は五・七・五・七・七の三十一音
    • 俳句と川柳は五・七・五の十七音
    • 自由律俳句には音の数の決まりがない

  4. 答え

    イ　短歌

くわしく：短歌、俳句、川柳

次の手掛かりすべてにあてはまる俳人はだれですか。

・弟子の曾良と、東北・北陸を歩いて旅した。

  1. 松尾芭蕉
  2. 小林一茶
